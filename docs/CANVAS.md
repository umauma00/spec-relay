# canvas で見る（試験中）

Copilot の canvas（チャットの横に開く画面）に、移行の進み具合・レビュー画面・承認済みの仕様を出します。中身は `render.mjs` の HTML と同じデザインです。どの項目にも「これを聞く」ボタンがあり、押して書いた質問がそのままチャットに届きます。

> canvas は Copilot 側で試験中の機能です（2026-11-18 時点）。Copilot app は提供済み、VS Code は Preview（1.142 以降、設定 `chat.canvases.enabled`、Copilot ハーネスのローカルセッションのみ）、Copilot CLI は実験的機能（`--experimental`）です。仕様が変わることがあります。canvas が使えないときは、今までどおり `render.mjs` の HTML をブラウザーで開いてください。

## 開き方

プラグインとして入れると、canvas の拡張（`com.github.copilot/extensions/spec-relay-canvas/`）も入ります。チャットで頼んでください。

```text
spec-relay の canvas を開いて
extract-billing-invoice のレビュー画面を canvas に出して
billing/invoice の仕様を canvas で見せて
```

| 画面 | 中身 |
|---|---|
| 進み具合 | 全体の状態、いまの作業と誰の番か、やること、レビュー待ちの変更（未確認の数）、機能ごとの状態。各画面へのリンク |
| レビュー画面 | `render.mjs --change` と同じ。確認印、残りの数、元コード |
| 仕様の一覧・仕様 | `render.mjs --spec` と同じ。検索つき |

- `openspec/` の下のファイル（変更・仕様・スクリーンショット・計画・設定）が変わると、数秒で画面も変わります（作り直しは要りません）。元コードや移行先のコードの変更では変わりません。
- 「これを聞く」で送った質問は、`[canvas]` で始まるメッセージとしてチャットに届きます。AI はそれに答えます。**承認や判断にはなりません**。承認はチャットで伝えるか、review.md に書いてください。
- canvas はファイルを書きません（この版では表示と質問だけです）。
- 画面の中のリンクのうち、canvas の画面どうしのリンクだけが開きます。画像の原寸表示や元コードのファイル、外部のサイトへのリンクは開きません（エディターやブラウザーで開いてください）。
- チャットのセッションが終わると、画面の上に「もう更新されません」と出ます。

## 守っていること

- 画面を出すのは、拡張が自分の PC の中だけ（`127.0.0.1`）で立てる小さなサーバーです。アドレスには毎回変わる合言葉（ランダムな文字列）が入り、ほかのホスト名からの接続や、ほかのページからの質問の送信は断ります。画面で動くのは、サーバーがその都度の印を付けたスクリプトだけです。
- 質問の文面のうち、対象（画面と項目の名前）は1行にまとめ、画面の名前はサーバーが決めます。
- 見せるのはリポジトリの中の Markdown と画像だけです。リポジトリの外を指すパスやシンボリックリンクの中身は読みません（ファイル名は見出しに出ることがあります）。
- canvas を閉じるとサーバーも止まります。チャットのセッションが終わると拡張も終わります。

## 自分で試す

Copilot なしで、ブラウザーで同じ画面を見られます（質問は端末に表示されます）。

```powershell
node "<キット>/scripts/canvas.mjs" --root .
```

表示された `url` をブラウザーで開いてください。止めるときは Ctrl+C です。

## わかっていないこと

- Copilot app と VS Code が、プラグインに入った canvas の拡張を読み込むかどうか（CLI は 1.0.79 からプラグインの拡張を読み込みます）。
- Windows の Copilot app での表示。
- AI が作業中に質問を送ったとき、すぐ割り込むか、作業の後に答えるか（拡張は「後で」を指定しています）。
